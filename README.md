# «Вершина» — вход редактора по паролю

Эта версия заменяет вход по токену GitHub на обычный пароль. Посетители видят результаты без входа. Редактор вводит пароль, выбранный владельцем; он не записан в HTML, JavaScript или репозитории. Проверка входа и прав на каждое сохранение выполняется на сервере. Сеанс действует до 8 часов или до закрытия/перезагрузки вкладки. При выходе доступ к редактору очищается.

## Установка на уже работающий GitHub Pages

1. Распакуйте архив.
2. В репозитории таблицы нажмите Add file → Upload files.
3. Загрузите файлы из архива непосредственно в корень репозитория, заменяя одноимённые файлы. Добавьте новый файл `api.js`.
4. **Не удаляйте и не заменяйте существующий `data.json`.** Его нет в этом архиве, чтобы сохранить ранее введённые данные. Старый файл `github.js` больше не используется; его можно оставить.
5. Нажмите Commit changes. Настройки Pages (main, /(root)) остаются прежними.
6. Дождитесь завершения публикации и обновите сайт сочетанием Ctrl+F5.
7. Нажмите «Вход для редактора», введите согласованный пароль, нажмите «Войти».
8. Если в старом `data.json` были классы, а серверная таблица ещё пуста, они загрузятся в черновик при первом входе. Проверьте их и нажмите «Сохранить для всех», чтобы перенести на сервер. Автоматической перезаписи нет.

## Работа

«Добавить класс» / «Изменить» → заполните поля → «Применить» → **«Сохранить для всех»**.

«Применить» меняет черновик только в текущей вкладке. Только «Сохранить для всех» обновляет общую таблицу на сервере. Сводки рассчитываются автоматически. Пустое поле отличается от нуля. При конфликте версий правки сохраняются в черновике; скачайте резервную копию JSON перед обновлением данных.

«Скачать CSV» выгружает таблицу. В режиме редактора доступна «Резервная копия JSON».

Слишком много неудачных попыток входа временно блокирует новые попытки. Не передавайте пароль людям, которым не нужно менять таблицу.

## Где сохраняются данные

Файлы интерфейса остаются на GitHub Pages. Общие данные и проверка пароля работают на отдельном сервере, адрес уже указан в `config.json`. Ни посетителям, ни редактору вход в ChatGPT не требуется. Токен GitHub для редактора больше не нужен.

Введённые после перехода данные сохраняются на сервере, а не обратно в `data.json` GitHub. Файл `data.json` нужен только для переноса старых данных и как резервная опубликованная версия при недоступности сервера. Актуальную резервную копию можно скачивать из редактора.
